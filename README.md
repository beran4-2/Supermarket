# Supermarket Simulator 🛒

Supermarket Simulator is a desktop simulation game developed in Java using the Swing library. The player takes on the role of a supermarket manager, responsible for managing finances, inventory, storage capacities, and staff efficiency. 📈

## Key Features 🌟
- **Economic System:** Dynamic buying and selling of products with real-time profit tracking. 💰
- **Inventory Management:** Expandable storage and shelf capacities to optimize workflow. 📦
- **Staff Automation:** Hire and manage employees to automate restocking and order fulfillment. 👨‍💼
- **User Interface:** Intuitive, full-screen graphical user interface with custom assets and smooth navigation. 🖥️
- **Data Persistence:** Configuration and game data are loaded from JSON files for easy customization. 💾

1. Ensure you have Java (JRE/JDK) installed on your system.
